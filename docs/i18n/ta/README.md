# Hearth ஆவணங்கள்

Hearth என்பது Zama Protocol மீது இயங்கும், இழப்பில்லா ரகசியப் பரிசுச் சேமிப்பு. நீங்கள் ஒரு ரகசிய
டோக்கனை டெபாசிட் செய்கிறீர்கள், உங்கள் இருப்பு செயினில் மறையாக்கப்பட்டே இருக்கிறது, பூல் ஈட்டும் வருவாய்
கால இடைவெளியில் நடக்கும் குலுக்கலில் பரிசுகளாக வழங்கப்படுகிறது, உங்கள் அசலை எப்போது வேண்டுமானாலும்
திரும்பப் பெறலாம். நீங்கள் எவ்வளவு சேமித்தீர்கள், எவ்வளவு வென்றீர்கள் என்பதை நாங்கள் உட்பட யாராலும்
படிக்க முடியாது.

Sepolia மீது ஏழு பூல்கள் இயங்குகின்றன, Zama அங்கு வெளியிடும் ஒவ்வொரு ரகசிய டோக்கனுக்கும் ஒன்று,
ஒவ்வொன்றுக்கும் அதற்கே உரிய ஒப்பந்தங்களும் அதற்கே உரிய கீப்பரும் உண்டு. கீழுள்ள பெரும்பாலான பக்கங்கள்
தங்கள் உதாரணங்களில் USDC ஐப் பயன்படுத்துகின்றன, ஏனெனில் மிக நீண்ட வரலாறு கொண்ட பூல் அதுதான்;
ஒவ்வொரு பக்கமும் ஏழு பூல்களையும் விவரிக்கிறது.

இது எப்படி இயங்குகிறது, எதை மறைக்கவில்லை என்பதற்கான முழுமையான எழுத்துப் பதிவு இந்தப் பக்கங்கள்.
களஞ்சியத்தின் மூலத்தில் இருக்கும் `ARCHITECTURE.md` என்பது அமலாக்க விவரக்குறிப்பு; இந்த மரம் அதே
வடிவமைப்பை, அதைப் பயன்படுத்துபவர்களுக்கும் தணிக்கை செய்பவர்களுக்கும் விளக்குகிறது.
