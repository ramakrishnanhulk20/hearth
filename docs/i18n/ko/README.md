# Hearth 문서

Hearth는 Zama 프로토콜 위에서 돌아가는 기밀 무손실 상금 저축입니다. 기밀 토큰을 예치하면
잔액은 체인 위에서 암호화된 채로 남고, 풀이 벌어들인 수익은 주기적인 추첨을 통해 상금으로
나갑니다. 원금은 언제든 인출할 수 있습니다. 얼마를 저축했는지, 얼마를 땄는지는 저희를 포함해
아무도 읽을 수 없습니다.

Sepolia에서 일곱 개의 풀이 돌아갑니다. Zama가 그곳에 공개한 기밀 토큰마다 하나씩이고, 풀마다
자기 컨트랙트와 자기 키퍼를 가집니다. 아래 문서 대부분은 예시에 USDC를 씁니다. 가장 긴 기록을
가진 풀이기 때문입니다. 다만 모든 문서는 일곱 개 풀 전부를 설명합니다.

이 문서들은 Hearth가 어떻게 돌아가고 무엇을 숨기지 못하는지에 대한 완전한 기록입니다.
저장소 최상위의 `ARCHITECTURE.md`는 구현 명세이고, 이 문서 묶음은 같은 설계를 쓰는 사람과
감사하는 사람의 언어로 풀어 쓴 것입니다.
