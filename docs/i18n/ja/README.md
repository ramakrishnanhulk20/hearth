# Hearth ドキュメント

Hearth は、Zama プロトコル上で動く機密性のある「損失のない賞金付き貯蓄」です。機密トークンを
預け入れると、残高はチェーン上で暗号化されたまま保たれ、プールが得た利回りは定期的な抽選で賞金
として配られます。元本はいつでも全額引き出せます。あなたがいくら貯めたか、いくら当たったかは、
私たちを含め誰にも読めません。

Sepolia では 7 つのプールが動いています。Zama がそこで公開している機密トークンごとに 1 つずつで、
それぞれが独自のコントラクトと独自のキーパーを持ちます。以下のページの多くは USDC を例に使って
います。履歴がいちばん長いプールだからです。どのページも 7 つすべてを説明しています。

これらのページは、仕組みと「隠さないもの」についての完全な記録です。リポジトリのルートにある
`ARCHITECTURE.md` が実装仕様であり、このツリーは同じ設計を、使う人と監査する人のために説明し
直したものです。
