# توثيق Hearth

‏Hearth هو ادخار سرّي بجوائز بلا خسارة، مبني على بروتوكول Zama. تودع توكناً سرّياً، ويبقى
رصيدك مشفّراً على السلسلة، ويُوزَّع العائد الذي يجنيه المجمّع كجوائز في قرعة دورية، ويظل
رأس مالك قابلاً للسحب في أي وقت. لا أحد، ونحن منهم، يستطيع قراءة ما ادّخرته أو ما ربحته.

سبعة مجمّعات تعمل على Sepolia، واحد لكل توكن سرّي تنشره Zama هناك، ولكل مجمّع عقوده الخاصة
وحارسه الخاص. معظم الصفحات أدناه تستخدم USDC في أمثلتها العملية، لأنه المجمّع صاحب أطول
تاريخ؛ لكن كل صفحة منها تصف السبعة جميعاً.

هذه الصفحات هي السجل المكتوب الكامل لكيفية عمل المنتج ولما لا يخفيه. ملف `ARCHITECTURE.md`
في جذر المستودع هو مواصفة التنفيذ؛ وهذه الشجرة هي التصميم نفسه مشروحاً لمن يستخدمه ولمن
يدقّقه.
